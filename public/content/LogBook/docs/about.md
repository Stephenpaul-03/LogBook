# About LogBook

LogBook is a modern documentation viewer designed to display project details, guides, and legal notices in a clean, minimalist layout.

## Vision

LogBook was built with the idea that documentation should be simple, lightweight, and blazingly fast. By doing away with heavy frameworks, it offers developer logs and guidelines instantly to users.

## Built With

- **Vite:** High performance frontend bundler.
- **React & TypeScript:** Robust component system and static typing.
- **Tailwind CSS:** Modern styling for layout elements.
- **Marked:** Fast markdown compilation directly on the client side.
