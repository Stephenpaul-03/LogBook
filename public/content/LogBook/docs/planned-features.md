# Planned Features

Below is our upcoming roadmap and planned feature set for LogBook.

## High Priority

- [ ] **Full-Text Search:** Enhance the Command Palette (`Cmd + K`) to search not just titles, but content inside markdown documents.
- [ ] **Custom Document Categories:** Dynamic folder-level scanning to generate sidebars without manually editing project sidebar JSON.

## Medium Priority

- [ ] **Page Transitions:** Add smooth page exit and entry animations using CSS/Framer Motion.
- [ ] **PDF Exporting:** Allow downloading markdown pages directly as styled PDF documents.
- [ ] **Localization:** Provide multi-language support toggle for sidebar topics.
